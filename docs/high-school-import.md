分類は[文部科学省の高校学習指導要領解説の教科構成](https://www.mext.go.jp/a_menu/shotou/new-cs/1407074.htm)を参照しました。普通科相当の共通教科と選択科目を対象とし、外国語は英語です。科目の履修学年は学校・課程で異なるため、本教材の学年は学習上の目安です。公式問題や公式監修教材ではありません。

国語は現代の国語・言語文化・論理国語・文学国語・古典探究・国語表現、地理歴史は総合科目と地理・日本史・世界史探究、公民は公共・倫理・政治経済、数学はⅠ・Ａ・Ⅱ・Ｂ・Ⅲ・Ｃ、理科は物理・化学・生物・地学の基礎と発展を扱います。英語コミュニケーションと論理表現のⅠ〜Ⅲ、情報Ⅰ・Ⅱ、保健体育、音楽・美術・書道・工芸、家庭基礎・家庭総合、総合的な探究・理数探究も含めます。これらの科目名があることを、科目全体の網羅とはみなしません。

## 問題数と網羅性

知識・説明問題277問と、55種類×40問の計算等2,200問です。数値違いを含む反復演習数で、2,477の独立した学習項目ではありません。数学に比べ言語・社会・実技系教科は少なく、**全範囲網羅という依頼には未達**です。

不足は、指導要領の全内容項目との一対一対応、長文読解・図表・証明・応用問題の厚み、音声の聞き取りと発話、体育・芸術・家庭の実技評価です。専門学科科目、英語以外の外国語は対象外です。知識・説明問題の全件専門家監修も未実施です。単元ごとの件数と不足は `private-data/school/high-coverage.json` に保存します。

## 再生成・登録・検査

問題本文と作問スクリプトはGit対象外の `private-data/school/` に置きます。公開版には教材を同梱しません。小中学校教材の `manifest.json` と高校の `high-manifest.json` は別に管理し、既存の教材ローダーが統合します。

```powershell
python private-data/school/author-high.py
python private-data/school/check-high.py
node checks/high-school-material-check.mjs
node private-data/school/register-high.mjs
node checks/high-school-material-check.mjs --built
node scripts/update-exam-inventory.mjs
```

計算検査は保存済み2,200解答を照合し、展開・因数分解の代入、組合せ列挙、差分による微分、数値積分なども使用します。残りの解答について専門家が独立監修したという意味ではありません。アプリ側の検査は形式、重複ID、学年・教科の対応、教材の遅延読み込み、演習の作成、登録前のパック保持を確認します。

検査結果：計算解答2,200問の照合、全3学年・11教科の実パック読み込み、演習作成・自己評価・保存復元、登録前パックのメタデータと本文ハッシュの保持、`npm run check` に合格しました。実ブラウザでの全問目視確認と専門家監修は未実施です。

登録時は既存パックを検証し、更新しないファイルだけをハードリンクで作業ディレクトリへ引き継ぎました。索引・台帳・新規問題は別ファイルへ書き、既存の排他ロックとディレクトリ交換による反映を使用しています。小中学校や資格教材の進行中の更新は停止せず、ロック解放を待って取り込みました。

クラウド配備はこの追加作業には含めません。
