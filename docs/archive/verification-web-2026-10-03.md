記録日：2026年10月3日。

教材を同梱していた構成から、公開準備・Webアプリへの整理までの記録です。各項目はその時点の構成に対する結果で、現在の公開対象・初期問題数を示すものではありません。現在の構成については [Web版の検証結果](../verification-web.md) を参照してください。

## 成功

- `node --check web/core.mjs` と `node --check web/app.mjs`：構文エラーなし。
- `node checks/web-check.mjs`：240問、10分野、問題文の重複なし、各分野20問以上。
- 100通りの模試抽出：145問重複なし、各分野14〜15問。少ない問題集での抽出も確認。
- 選択肢の順序・選択中の回答の保存形式と復元。
- 通常演習：回答確定時に記録、二重記録防止、スキップ、途中終了で未出題の問題を累計記録へ加えない。
- 模試：回答中は累計記録へ加えず、終了時に未回答を含めて一度だけ記録。
- 締切の丸め、時間切れ後の回答拒否・採点、最終回答後の採点。
- 持込問題とバックアップの検証：不正な形式、番号、重複、存在しない問題、回答順序、選択肢順序の破損を拒否。
- 保存処理：保存失敗時は既存の保存データを保持。別タブによる更新を上書きしない。
- HTTP配信：全6ファイルが200で応答。JavaScriptモジュールはJavaScriptのMIMEタイプ。
- 起動スクリプトのPowerShell構文チェック。
- 既存のライト／ダーク配色における本文、補足文、ボタン、選択状態の20組のコントラスト：すべて基準4.5:1以上。

## 自動同期の追加検証

- `npm run check`：既存の学習処理と同期のチェックが成功。
- 2端末の学習記録・ブックマーク・持込問題・途中の演習の引き継ぎ。
- 古い端末からの更新を拒否し、クラウドの新しい記録を保持。端末のバックアップ後にクラウドの記録へ切り替え。
- 通信失敗後の端末保存と、再起動・再接続後の同期。
- 保存応答の消失と送信中の追加変更の回復。未同期の変更を失わない。
- 同時更新で1件だけを確定するSQLトランザクション。不正データの拒否、DB障害時のロールバック。
- D1の1行上限を超える2000問の持込問題と絵文字を分割保存・復元。
- 実際に署名したJWTを使い、本人・許可外メール・署名改変・期限切れ・AUD/ISS/EXP欠落・外部送信元を確認。
- `npm run build:cloud`：Cloudflare Functionsのコンパイル成功。
- `npm run check:runtime`：コンパイル済みWorkerをCloudflareのローカル実行環境で動かし、実際のローカルD1へ保存。教材ファイルの認証、本人アクセス、同時更新とCSRF拒否が成功。
- `node checks/cloud-browser-check.mjs`：独立した2つのChromeブラウザコンテキストで、回答・ブックマーク・別端末の演習再開を実操作。PC幅1100px・スマホ幅390px、ライト／ダーク、未同期・競合表示、横はみ出しなし、Tabで操作対象へフォーカスできることを確認。

本人の本番ログインと実端末間の同期は未検証です。Accessポリシーの本人限定ルールも、利用者の環境で確認してください。配置手順は [クラウド設定](../cloud.md) を参照してください。
