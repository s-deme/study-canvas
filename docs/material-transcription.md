## 画像・PDFの全件抽出と図だけの切り抜き

`npm run build:material-text` は、最新の軽量化ビルドに残る問題・解答・解説の画像を重複排除して全件抽出する。PDFの領域と原本ハッシュが分かる画像は直接抽出を優先し、スキャンや画像単体は日本語・英語OCRを使用する。原本PDFが一致する既存の全文OCRは領域内の行が完全に収まる場合に再利用する。領域情報のない画像にもOCRを実行する。画像ハッシュ・PDFハッシュ・抽出文字ハッシュを保存し、中断後は画像単位のキャッシュから再開する。

図形・画像と文字を分離できるPDF領域では、原本PDFを描画した画素と既存画像の画素が一致することを確認してから、図形を囲む領域を切り抜く。切り抜きの境界に線や文字が触れる場合は、原画像を保持する。図注・凡例・図内の文字は切り抜き側に残し、読める文字は補助テキストにも含める。画像内の位置関係を文字だけで再現したとは扱わない。埋め込まれた画像内の文字や、直接読めない文字は切り抜きにOCRを行う。図の隣の表は別に判定し、文字・セル・罫線を再現できるものを文字化する。白背景の表は、後から描かれた背景に文字が隠れていないことも検査する。切り抜きは元画像からの画素コピーであり、描き直さない。元画像・元PDF・旧ビルドは削除しない。

文字は既存の共通本文・解説欄に「原本未照合」の補助テキストとして追加し、正答・選択肢・採点対応を変更しない。照合済みの欄は自動抽出で上書きしない。切り抜き済みの問題は本文を先に常時表示し、図だけの画像を後に表示する。解答・解説画像由来の文字は、その由来を明記した解説欄に置き、模範解答や理由解説が新しく生成されたとは扱わない。

## 既存処理で確認した原因

- `prepare-material.py` はPDFの本文または既存OCRキャッシュのブロック順で本文を結合し、NFKC正規化する。上下付き文字・誤読・ページ末の版面情報は意味と照らす再検査が必要。
- `ocr-material.py` の既存キャッシュは主に150dpiのページOCR。回転は扱うが、解像度変更・本文と選択肢の領域別再抽出・校正済み内容の記録は別途必要。
- `prepare-github-material.py` は直接抽出を優先し、画像の問題区切りには余白領域OCRも使う。本文はブロック順なので表のセル関係や、図形として描かれた空欄記号a/bが文字列から失われる例がある。
- `prepare-material.py` の記述式解答分割は最初の「設問」から始まる。この前にある出題趣旨は `modelAnswer` に入らず、従来表示にもない。採点講評は汎用の解説欄に入り、種別が見えにくい。
- `compact-material.py` の `native_text` は画像を除去しても安全な領域を判定する。罫線・画像・数式・コードがあれば拒否するが、この拒否は文章部分まで文字化不可能という意味ではない。この保守的な画像除去判定を緩めず、画像併用の校正経路を追加した。
- 検索は問題文・選択肢・共通本文・解説を含む一方、`modelAnswer` と `evaluationGuide` が対象外だった。両方を追加した。

## 保存・生成・原本保護

`private-data/material-transcription/corrections.json` に問題ID、修正前の許容値、修正後、項目別の照合状態、原本PDFのSHA-256、1始まりのPDFページ、領域（PDF座標）、照合方法、確認日、校正理由を保存する。校正者は作業したCodexであり、独立した人間のレビューを主張しない。ファイルは非公開のローカル教材としてGit対象外。再開やバックアップにはこのファイルも含める。

`material-transcription.mjs` は原本ハッシュと修正対象の旧値を検査し、未確認OCR・古くなった校正・問題IDや正答インデックスの変更を拒否する。同じ校正の再適用は可能。取り込み側の本文が変わった場合は推測で上書きせず停止する。

`build-material-transcription.mjs` は成功済みビルドから新しいローカル派生ビルドを作る。既存のバリデーション、本文パック圧縮、共通本文共有、試験別索引を再利用する。全パックの元ハッシュと全問題のID・並び順・出典・年度・解答形式・正答対応・画像参照を確認し、完成後だけ `build/material-transcription/current.json` を更新する。元ビルドと旧派生ビルドは保持する。画像は保持した成功ビルドへのディレクトリジャンクションで参照するため、ローカル候補単体では移動・配備しない。

既存 `compact-private-material.mjs` にも校正適用を追加した。原本を再取り込みした後の派生生成でも校正が残る。既存の画像圧縮・旧URL互換・正答検証は維持する。校正を行ったという理由で画像を除去する処理は追加していない。

アプリは `textReview` を保持し、全体画像を保持する未照合本文は補助テキストとして折りたたむ。照合済み本文と、図だけの切り抜きに置換した本文は常時表示する。未照合の表示は維持する。解答例・出題趣旨・採点講評を区別する。利用者が文字や選択肢を編集した場合、その欄の照合済み状態を引き継がない。選択肢が変わった場合は正答対応の照合状態も落とす。

問題文・共通本文・形式を編集した場合も、関連する正答・解答例・出題趣旨・解説の照合状態と公式解答の種別を引き継がない。変更がない欄の文字そのものの照合状態と、変更後の問題に対する解答の対応は区別する。

狭い画面では表の列見出しを過度に分割せず、横スクロールで列の対応を保つ。表とコードのスクロール領域はキーボードからフォーカスでき、既存のフォーカス表示を使う。
