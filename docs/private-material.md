# 本人用教材の管理

現在の登録数は [試験管理表](exam-inventory.md)、取り込み状況は [教材の取り込み状況](import-status.md) が管理元です。この文書にある件数・検証・配備は各実施時点の履歴です。更新手順は [docs案内](README.md) を参照してください。

公開配信元は `web/`、本人用生成物は `build/private/web/` です。教材原本・OCR・確認した問題区切りは `private-data/` に保存し、Gitには含めません。学習記録に配布教材の本文・画像を複製しません。利用者による編集は持込問題として配布教材より優先されます。

## 収録範囲

既存のG検240問、SG15問、FE26問、簿記3級20問のIDを維持します。AP・ST・SA・PM・NW・DB・ES・SM・AU・SCは2023〜2025年度の実施回・全科目を対象に、IPAの年度別公開資料から取得します。共通の午前Ⅰは各試験に所属させ、記録を試験ごとに分離します。設問単位の記述、DBの括弧番号の設問、論述は大問単位です。ES午後Ⅱも論述として扱います。

## 再生成

Python 3.12、PyMuPDF 1.28.2、Pillow 12.3.0を使用します。Python依存は `build/python-deps/`、日本語・英語のtessdata_fastは `build/tessdata/` に配置します。原本・OCRキャッシュを保持すれば通常は再取得・OCR不要です。

```powershell
python scripts/fetch-material.py
python scripts/ocr-material.py
python scripts/review-material.py
# markers画像を原本と照合し、確認済み区切りをprivate-data/ipa/verified-starts.jsonへ保存
python scripts/prepare-material.py
python scripts/verify-material.py
npm run build:private
node checks/private-material-check.mjs
```

`errors.json` が空でない場合はビルドを停止します。問題区切りを変更した場合はgeometryキャッシュの比較で画像も再生成します。原本のURL・SHA-256・収録件数・検査結果は教材画面に、全出典と問題番号対応は本人用 `material/audit.json` に記録します。補助テキストはOCRで誤認を含み得るため、問題の原本画像を正本として確認します。図表は画像を開いて拡大できます。論述の出題趣旨・採点講評は評価資料と表示し、模範解答として扱いません。

## PCとクラウド

`Start-Web.ps1` は準備済み教材がある場合に本人用ビルドを生成して配信します。通常の公開用チェックは本人用生成物を配信しません。

GitHub候補の追加教材を含む全33,485問は本人用ローカル版に登録しています。クラウドのファイル数上限を超えるため、通常の `build:private` はローカル用として生成し、`build:private-cloud` は `--cloud` を付けて上限を検査します。公式原本教材の内訳は [収録結果](github-material.md)、未登録試験の追加と保留理由は [候補の取り込み結果](github-import-results.md) を参照してください。

```powershell
npm run build:private-cloud
node checks/private-runtime-check.mjs
node checks/private-browser-check.mjs
npm run deploy:private
```

実ブラウザ検査には専用プロファイルのChromeデバッグポート9238を使用します。個人の通常ブラウザプロファイルは検査に使いません。

本人用配備でも既存Pages・Access・D1を使用し、本文JSON・図表・索引を含む全パスを本人JWT検証の対象とします。公開用は `npm run build:cloud` / `npm run deploy:cloud`、本人用は上記コマンドです。公開用コマンドを本人環境へ実行すると教材のない版になります。
