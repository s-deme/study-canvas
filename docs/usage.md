# 使い方と学習記録

ローカル版の起動、演習、記録の保存・復元について説明します。クラウドで利用する場合は [クラウド設定](cloud.md)、問題を用意する場合は [問題の取り込み形式](question-format.md) を参照してください。

## PCで起動

Python 3が入っているWindowsでは、`Webアプリを起動.cmd` をダブルクリックしてください。ブラウザで **http://localhost:8765/** が開きます。起動用のウィンドウは使用中に開いたままにしてください。終了はCtrl+Cです。

コマンドから起動する場合：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

起動後、ブラウザで http://localhost:8765/ を開きます。`web/index.html` を直接ダブルクリックせず、HTTPサーバー経由で開いてください。最初の画面から問題を取り込めます。

## 同じWi-Fiのスマホで使う

PCで次のコマンドを実行し、PCを起動したままにしてください。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Web.ps1 -LAN
```

PCで同じポートのサーバーが動いている場合は、先にCtrl+Cで終了してください。`ipconfig` でPCのIPv4アドレスを確認し、スマホで `http://PCのIPv4アドレス:8765/` を開きます。たとえば `http://192.168.1.10:8765/` です。Windowsの通信許可が表示された場合は、自宅など信頼できるプライベートネットワークで使用してください。スマホで `localhost` を開くとPCには接続できません。

この方法は同じネットワーク内向けです。外出先から本人限定ログイン・自動同期付きで使う場合は、Cloudflare Pages・Access・D1を設定し、`web/` と `functions/` を配信します。`web/` だけのアップロードでは同期機能は動きません。

## 試験を選ぶ・追加する

画面上部の試験選択から切り替えます。初回はG検を選択しています。G検・SG・FE・簿記を含むすべての試験は問題未登録で始まります。手持ちの問題を登録してください。試験名の初期設定は問題集の同梱を意味しません。

「試験を追加」で試験名を入力すると、IT以外の試験も登録できます。分野・科目・学習分野は任意です。ホームの「試験・問題を管理」から設定を編集できます。

問題は画面で登録・編集するか、JSON・CSVを取り込みます。取り込み内容を確認し、登録ボタンを押して確定してください。エラー時は保存しません。管理画面の「JSONの見本」「CSVの見本」をダウンロードして取り込むと、形式確認用サンプルで動作を試せます。詳しい形式は [問題形式](question-format.md) を参照してください。

## 学習機能

- 今日の10問、科目・分野別演習、復習、ブックマーク、検索・1問演習。
- 単一選択・複数選択。複数選択は正解の集合と完全に一致したときだけ正解。
- 記述・論述は入力して回答を確定し、模範解答を見て「できた／一部できた／要復習」を選びます。正答率には混ぜません。
- 表・コード・共通本文・図を表示。図をタップすると拡大できます。
- 選択式の練習模試：最大20問／15分。G検には最大145問／100分・120分もあります。登録数が少ない場合はその件数で実施。
- 試験ごとの回答記録、自己評価、復習対象、直近30回の履歴。
- 選択中の選択肢・入力中の記述回答・途中の演習を保存して再開。

選択式は通常演習の回答確定時、記述・論述は自己評価時に記録します。「一部できた」「要復習」は復習対象に入り、「できた」で外れます。スキップも要復習として記録します。通常演習の途中終了では未表示の問題を累計に加えません。模範解答を表示した記述問題は、自己評価してから次へ進む・終了してください。

模試は選択式のみで、終了後に解説を表示します。中断中も時間は進み、途中終了・時間切れの未回答も不正解として記録します。本番の採点・合否判定を再現するものではありません。

途中の演習は全体で1つです。試験を切り替えても保持し、ホームの「演習を再開」で元の試験に戻れます。新しい演習を始めるときは置換の確認を表示します。

## 記録とバックアップ

「記録」からバックアップを書き出し、別端末の「バックアップを読み込む」で移せます。バックアップは全試験を含みます。復元すると、そのブラウザの試験一覧・記録・持込問題・途中の演習を置き換えます。復元ファイルは10MBまでです。不正な形式は取り込まず、既存の記録を保持します。

ローカル版の記録はブラウザの `localStorage` に保存します。端末・ブラウザ・URLごとに別の記録になります。`localhost` とPCのIPアドレスでも保存場所は別です。クラウド版では同じ配信元にログインした端末間で自動同期します。変更から約0.5秒後・画面へ戻ったとき・通信復帰時・表示中15秒ごとに同期します。端末を切り替える前に「同期済み」を確認してください。通信失敗時は端末に記録を残し「未同期」と表示します。競合時は自動上書きを止め、端末の記録を書き出してからクラウドの記録を読み込めます。ブラウザのデータを消す前にバックアップしてください。

Web版はPWAではありません。最初のアクセスと再読み込みには配信元へ接続できる必要があります。PCから配信している場合、PCを停止するとページを再読み込みできません。

## 以前のデータの引き継ぎ

以前の同梱問題（SG・FE・簿記）の回答記録と途中の演習も保持します。教材が未登録の間は採点・再開せず、同じ試験ID・問題IDの教材を登録すると利用できます。記録の保持のために問題本文を公開版へ戻すことはありません。

旧バージョンの記録は初回読み込み時に検証してからバージョン2へ移行します。問題ID・回答記録・日別記録・途中の選択肢は維持します。移行前の保存データを同じブラウザの別キーに退避し、検証・保存に失敗した場合は元データを保持します。元の教材が未登録の記録は、同じIDで再登録すると使えます。

study-canvasへの名称変更後も、保存キーは従来と同じ `gstudy.web.v1` です。同期ロック名も維持し、旧タブとの同時書き込みを防ぎます。フォルダ名の変更だけではブラウザの記録は移動・削除されません。同じブラウザ・URLで利用してください。

URLやポートを変更する場合は、元のURLでバックアップを書き出し、新しいURLで読み込みます。新しい試験の履歴は試験IDと問題IDで識別します。クラウド版も同じ形式を扱い、データベースの追加マイグレーションは不要です。更新後は開いている古いタブを再読み込みしてください。


本人用の教材復帰・年度別教材・公開版との分離については [本人用教材の管理](private-material.md) を参照してください。
