# Web版の検証結果

記録日：2026年10月4日。問題登録と学習の仕組みを公開し、問題データは形式確認用サンプルだけに限定した構成で検証しました。

## 今回成功したチェック

|チェック|確認内容|
|---|---|
|`npm run check`|採点・模試・保存・競合、試験間の分離、4種類の解答形式、旧データ移行、JSON・CSV、利用者が登録した問題の同期。|
|公開チェックと回帰テスト|空の初期問題一覧、サンプル3ファイルの件数・出典、静的ファイル許可リスト、非公開教材・旧問題集・個人設定・生成物の誤追加拒否。|
|`npm run build:cloud`|問題集を組み込まないCloudflare Workerのコンパイル。|
|`npm run check:runtime`|コンパイルしたWorker、ローカルD1、JWT、同時書き込み、CSRF拒否。|
|`npm run check:browser`|全4試験が問題未登録で始まること、旧教材・図・非公開データの404、任意の試験と問題の登録・編集、JSON確認・重複拒否・CSV、採点・自己評価、再読み込み・バックアップ復元、端末間同期。|
|`node checks/cloud-browser-check.mjs`|初期状態、非公開ファイル404、取り込み・再読み込み、途中再開、オフライン・競合、旧G検記録の保持・教材の再登録。|
|以前の61問を使ったローカル互換性確認|SG・FE・簿記の未送信回答・回答済み・終了済み演習とまとめた回答記録を、空の初期問題一覧で読み込めること。|

ブラウザ検証は隔離したヘッドレスChromeと使い捨ての認証付きローカルサーバー・SQLite DBで実行しました。320px・390px・1100px、ライト／ダーク、文字拡大、キーボードフォーカスも回帰チェックが成功しています。本番クラウドには接続していません。

## 公開対象

公開候補は44ファイル・約0.25MBです。問題データは `web/sample-questions.json`（旧形式1問）、`web/sample-questions-v2.json`（単一選択・記述式2問）、`web/sample-questions.csv`（複数選択1問）の形式確認用自作サンプルだけです。サンプルは自動登録せず、利用者が取り込みます。

以前のSG・FEの41問、簿記の20問、図49枚、教材生成スクリプトと旧Workerは、手元のGit管理外 `private-data/retired-material/` に保管しました。公開ファイルと新しいWorkerへの教材本文・解説の混入がないことを検査しています。以前の問題IDの識別のみ残し、既存記録を保持します。教材が未登録の演習は採点・再開せず、同じ試験ID・問題IDで登録すると使えます。

管理先は [s-deme/study-canvas](https://github.com/s-deme/study-canvas) です。`origin`は設定済みですが、初回コミット・push・本番配備は行っていません。
