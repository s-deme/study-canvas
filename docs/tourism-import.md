## 形式と検証範囲

- 問題・図・選択肢・共通資料を原本画像で保持。単一選択と複数選択を区別し、掲載正答で採点します。理由解説は未収録です。
- 総合旅行の国内・海外実務は科目全体と資料編、通訳案内士は科目全体の画像を表示します。通訳案内士の設問指定には大問番号ではなく、四角で囲まれた「解答番号」を使います。
- 公式・外部資料のSHA-256、問題と正答の対応、生成画像の原本画素、出典・年度・問題ID・選択肢数、アプリでの正誤判定を検査します。既存パックのハッシュを開始時点の記録と比較します。
- JNTOの2026年3科目及び2024年一般常識の画像正答表は、全解答セルを目視し原本ハッシュに固定しました。2024年一般常識は本文省略もあるため収録保留です。ANTAの2024〜2026年の枝問位置も正答表の原本で確認しました。
- 問題本文のOCRは省略箇所を検出する補助です。OCRで正答を推測しません。全設問の本文・選択肢・図の目視確認と解説検証は未実施です。

すべての新規パックを`localOnly`に設定。本人用ローカルビルドへ反映し、公開版・クラウド版へは配備していません。

## 非収録・保留

101候補のうち83パックを収録、18パックを保留しました。収録パック内でも381設問を除外しています。詳細は`private-data/github-material/prepared/tourism-report.json`の`reason`と`excludedQuestions`です。

- 運行管理者のA〜D別の字句選択・複合正誤など、正答を通常の選択肢に確実に対応できない設問。
- 国内旅行の2024〜2026年の枝問4件。2022・2023年の国内実務は枝問の反復番号が未対応。
- 通訳案内士の2022年歴史、2023年地理、2024年一般常識、2025年地理は、著作権による本文・画像の省略があり科目全体を保留。実務科目及び外国語科目は設問別の選択肢数・枝問・省略箇所の確認が未対応。
- 旧資料のリンク切れ、スキャン正答表、問題番号の不一致。取得しただけのPDFは問題数に含めません。

## 再生成

```powershell
python scripts/prepare-tourism-material.py --fetch
python scripts/prepare-tourism-material.py
python scripts/verify-github-material.py
npm run build:private
node checks/tourism-material-check.mjs
npm run inventory:exams
```

原本・画像・正答表の確認記録は`private-data/github-material/`へ保存します。正答表の目視確認記録は`tourism-reviewed-keys.json`です。この確認記録を持たない環境では、画像だけの正答表を持つ科目は収録保留となります。ビルドは既存の共有ロックに従います。
