## 重複・検証・保留

公式正答表のセル座標を読み、番号1〜50の連続性を確認します。正答なし・複数許容正答は通常の単一選択問題として追加しません。画像のみの問題や文字コードが壊れたページはOCRを使い、同じ行の断片を座標で統合します。欠けた見出しは対象ページを再確認し、数字を順序から推測して補いません。判定できない冊子は保留です。

既存問題の本文と先頭3選択肢が原本に一致したもの、または既存GitHubデータに同年度・同設問番号が明記され公式正答も一致したものを除外します。後者は宅建の `hangonkou-ux/takken-app` とマンション管理士の `pousan/mansion-exam-prediction` が対象。宅建の12月試験は10月試験と別に扱います。表記を変えた問題や意味重複の全面除去は保証しません。

検証時は別方式のテキスト順で公式正答を再照合し、文字読み出しが特殊な正答表は目視転記と原本ハッシュで照合します。宅建2021年10月・2024年と管理業務主任者2008年の正答表は全150セルを目視確認。全問題画像は原PDFのページを再描画し、画素一致を検査します。解答表のページは問題画像へ混ぜません。全設問の目視確認、理由解説の作成、現行法に対する正誤の再判定は未実施です。

正答・出典・年度・原本画像を収録し、理由解説がないことと当時の法令が前提であることを問題画面に表示します。保存先は `private-data/github-material/estate-discovery.json`、`prepared/estate-report.json`、`estate-reviewed-keys.json`。保留・重複除外の理由は報告JSONに保存します。

表紙のない原本は先頭ページの初期問題の見出しを確認して含めます。回転した原本は表示方向に描画してからOCRにかけ、字が小さい見出しはその部分だけを拡大して再確認します。問1〜50の明確な見出しが揃う場合だけ、番号を持たない注記見出しを除外します。途中ビルドへの依存を避けるため、既存2,129問は `estate-existing.json` に固定保存し、元のパック情報は `estate-baseline.json` に残します。新しいGitHub候補を追加した後は、この重複判定用スナップショットも更新してください。

## 再生成

```powershell
python scripts/prepare-estate-material.py --fetch
python scripts/prepare-estate-material.py
python checks/estate-material-check.py
python scripts/verify-github-material.py
npm run build:private
npm run inventory:exams
```

目視確認の記録と保存済み原本が必要です。本人用ビルドは既存の共有ロックに従います。再取得時は保存済み原本を再利用します。
