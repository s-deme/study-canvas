後続の増量は [小中高の問題増量](school-expansion.md) を参照してください。以下は初回9,104問の作成記録です。

2026-10-08作成。小学1年〜中学3年を教材、教科を科目、単元を学習分野として登録します。既存の検索・科目絞り込み・分野別演習・学習記録を使います。

今回の小中学校分は **9,104問・9学年・98学年別教科パック**。教材上の学年×教科×単元の組は1069件です。同じ単元を別の学年で反復する場合を含み、独立した学習事項が同数あるという意味ではありません。

## 範囲と限界

- 国語、算数・数学、生活、社会、理科、外国語活動・英語、音楽、図画工作・美術、体育・保健体育、家庭・技術家庭を収録。道徳・総合的な学習・特別活動は考察や活動計画の課題として分離しています。設置されない学年の教科は追加していません。
- 国語は文字・文法・語彙・説明文と物語の読解・古典の基礎など。算数・数学は数と計算、図形、測定・関数、データの活用。社会は地域、産業、地理、歴史、公民。理科は生命、物質、エネルギー、地球の分野を扱います。英語は語彙、文法、英作文などです。
- 小学校の教育漢字1,026字は、文科省の配当表にある全字を各学年へ対応させました。中学校分は残る常用漢字1,110字です。各字に読みと画数の2問、計4,272問があります。読みは正答例であり、全ての音訓・熟語・文脈別用法・書き取りを網羅した意味ではありません。
- 中学校内の漢字は辞書の頻度を目安に370字ずつ配分しています。社会の地理・歴史、英語、音楽・実技教科なども複数学年で扱う範囲を教材上で配分・反復しています。教科書や学校の年間計画による順序差があり、公式にその学年へ固定された単元と断定しません。
- 数値を替えた計算演習3,410問を含みます。全問を異なる概念の問題とは数えません。四択の誤答は数値の近い選択肢で、誤概念ごとの精密な診断用には設計していません。
- **全学習範囲の網羅は未達・未認定です。** 学習指導要領の全項目と問題の一対一対応、全教科書の単元照合、知識問題の専門家による全件監修は未実施です。公式CSV全件の参照台帳と教材の単元別件数を保存していますが、台帳があることを網羅の証明にしません。
- 未充足：文脈中の漢字書き取り、長い文学作品・古典、地域固有の調査、地図・実験図・グラフの視覚問題、外国語の音声付き聴解・対話、実験操作、歌唱・器楽・制作・運動の実演評価。実技教科の説明・計画問題は実技そのものの代替ではありません。
- 道徳は唯一解や人格の点数化をしません。考えた理由や他者の立場を振り返る自己評価です。低学年の文章課題には大人の読み上げ補助を想定したものがあります。

## 出典・利用条件

- 学習範囲：[文部科学省・学習指導要領本文／解説](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)、[学習指導要領コード表](https://www.mext.go.jp/a_menu/other/data_00002.htm)。小学校82V12・中学校83V11のCSVを保存し、SHA-256を記録しました。公式のテスト問題を転載した教材ではありません。
- 漢字の読み・画数：[KANJIDIC2](https://www.edrdg.org/kanjidic/kanjd2index_legacy.html)、© Jim Breen and the Electronic Dictionary Research and Development Group。2026-10-07版を抽出・加工。[利用条件](https://www.edrdg.org/edrdg/licence.html)、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。漢字問題ごとに帰属とライセンスを表示します。SKIPなどの別条件の項目は使用していません。
- その他の設問・解答例・解説はAIによる自作です。公式問題、教科書準拠教材、専門家監修済み教材とは表示しません。問題本文・生成元・辞書データは `private-data/school/` に保存し、公開リポジトリへは含めません。

## 保存と再生成

アプリの学年選択から「一般教材・義務教育」の小学1年〜中学3年を選び、教科と単元を絞ります。四択は自動採点、記述・実践課題は模範解答や評価の観点で自己評価します。持込問題2,000問枠は消費しません。本人用ローカル版への登録で、クラウド配備は行いません。

```powershell
python private-data/school/author.py
python private-data/school/check.py
node scripts/append-food-material.mjs school
node checks/school-material-check.mjs
python private-data/school/report.py
npm run inventory:exams
```

初回の追加は既存教材を保持する排他・一括置換の登録処理です。同じ内容の再実行は重複追加しません。IDと分類が変わらない内容修正は `node private-data/school/register.mjs` で反映できます。変更しないファイルをハードリンクし、変更ファイルは別に作成してから一括置換するため、既存の本文や画像を書き換えません。IDや分類を変える場合は `npm run build:private` で全体を再生成します。IDは学年・教科・問題文のハッシュから作り、同一の問題文なら学習記録のキーを保ちます。別作業の高校教材は別マニフェストです。

参照元を更新するときは文科省CSV、KANJIDIC2と利用条件を再取得し、生成・照合・ビルドを実施します。KANJIDIC2の定期更新条件も確認してください。月次で提供元版を確認する運用を想定しますが、自動スケジュールは登録していません。

ローカルの `unit-coverage.csv` が学年・教科・単元別の件数、`curriculum-inventory.json` が公式CSVの全参照行です。両者の自動キーワード一致を網羅率とは扱いません。

## 検査

- `check.py`：計算演習3,410問を別の計算処理で再計算し、表示正答と照合。単純計算は問題文からの数値抽出とも照合。教育漢字の配当、全2,136字の読み・画数を原辞書に照合。
- `checks/school-material-check.mjs`：形式、重複、改変拒否、全9学年・98教科パックの読み込み、教科分類、採点、状態復元を検査。ビルドへ登録された場合は全問題一致と追加前パック保持も検査。
- 2026-10-08実画面検査：隔離Chromeで9学年×選択・記述・論述の27ケースを操作し、科目絞り込み、出典、解答前の正解非表示、採点・自己評価、再読込後の保存、390px幅の横はみ出しなしを確認。四択の誤答候補の偏りを修正した後、全9学年の選択式を再検査しました。問題IDと分類は維持しています。
- `npm run check` と公開教材混入防止検査は合格。登録済み全9,104問の一致と、開始時111,143問の既存パック情報保持も合格。同時進行の別教材追加はこの9,104問へ加算しません。
- これらは知識問題の専門家監修や、全問の実画面目視、全範囲網羅を保証する検査ではありません。実行結果はローカルの `verification.json`、`browser-results.json`、`choices-browser-results.json`、`session-verification.json` を参照します。
