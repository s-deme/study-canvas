## 検査と限界

- 重複は既存学校教材と追加候補全体で、NFKC正規化・空白除去後の問題文を照合し、2,285件除外しました。言い換えや数値違いの意味的重複をすべて除いた件数ではありません。
- 抜き取りで発見した条件不足2件、選択肢不備5件、必要図版がない1件を除外しました。除外元ファイル・行番号・理由は `expansion-excluded.json` に記録しています。
- 自作23,055問は、表示問題文の数値と入力値の一致、および解答を別計算で全件検査しています。
- 外部52,489問は原データの本文・選択肢・解答との対応を検査しています。**全件の正答を独立に照合・専門家監修したものではありません。** 提供元の `verified: true` を、本アプリでの正答確認済みという意味には使いません。各問題に「正答未独立照合」を表示します。
- 外部AI問題の解説は英語を含みます。分数・根号・主要な数式記号をプレーンテキストへ整形し、未知のLaTeX記法は勝手に解釈せず残しています。完全な数式組版ではありません。四択とMGSMに詳細解説がない場合は、そのことを表示します。
- 学年は提供元分類を基本にした目安です。数学IIIC、海外の高校水準、MGSM発展問題などは国内の履修学年・難度と厳密に一致しません。中学校分類にも先取り問題が混ざり得ます。
- 今回は算数・数学中心の増量です。国語・英語・実技教科の増量、音声・地図・図版の追加、全科目の範囲網羅は達成したと扱いません。

## ローカルでの利用・再現

既存の小学1年〜高校3年を選び、教科・分野で絞って出題します。JMMLUは自動採点の四択、その他は模範解答と比べる記述式です。追加問題は88パックに分割し、学年選択後に読み込みます。持込問題2,000問枠は使いません。

教材と生成・取得スクリプトは、従来どおりGit対象外の `private-data/school/` に置きます。公開版への同梱・GitHubへのpush・クラウド配備は行っていません。

```powershell
python private-data/school/fetch-expansion.py
python private-data/school/expand.py
python private-data/school/check-expansion.py
node checks/school-expansion-check.mjs
node private-data/school/register-expansion.mjs
node checks/school-expansion-check.mjs --built
node checks/school-material-check.mjs
node checks/high-school-material-check.mjs --built
npm run check
npm run inventory:exams
```

取得は固定コミットから行い、保存済みファイルを再利用します。更新版を取得する操作とは別です。全件ビルドでも `scripts/school-material.mjs` が追加マニフェストを読み込みます。登録は既存の排他ロック・ハードリンク・ディレクトリ交換処理を使用し、同じ内容の再実行は追加しません。変更済みパックへの上書きは拒否し、必要なら検証後に全件ビルドします。

原本や生成器が変わるとハッシュ検査で停止し、再生成・再検査するまでビルドできません。既存教材の本文とパック情報の保持も登録後に検査します。現在の全教材集計は [試験管理表](exam-inventory.md) を参照してください。

増量後の索引は約41MBです。ローカル再生成に誤適用されていたPagesの25MB上限はクラウドビルド時だけに限定しました。学年内のパックは順番に読み込む既存方式なので、学校教材の大きな学年を初めて開く際は読み込み時間が増えます。

検査結果：全75,544問の形式・原データ対応・重複検査、自作23,055問の数値照合、既存122,724問の全パック保持、同一内容の再登録、`npm run check` に合格。12学年の追加元別16ケースを隔離Chromeの390px画面で操作し、教科絞り込み、出典表示、正答の事前非表示、採点・自己評価、再読込後の記録保持、横はみ出しなしを確認しました。全問目視・全外部正答の独立検証をした意味ではありません。

実行記録は `expansion-verification.json`、`expansion-browser-results.json`。公開教材混入防止を含む全体テストも合格しました。

全件再生成も完了し、198,268問・2,572パック・58,374ファイルを生成しました。反映前に、増量後の登録済み全パックと本文SHA-256・パック情報・総件数が完全一致することを検査しました。41MB超の索引を含むローカルビルドが25MBのクラウド制限で停止しないことも、この実行で確認しています。記録は `expansion-rebuild-verification.json` です。
