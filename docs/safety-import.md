## 再生成と検査

```powershell
python scripts/prepare-safety-material.py --fetch
python scripts/prepare-safety-material.py
python scripts/prepare-safety-material.py --verification
npm run build:private
node checks/safety-material-check.mjs
npm run inventory:exams
```

原本は `private-data/github-material/`、問題JSONと画像はその `prepared/`、アプリ用生成物は `build/private/web/`。既存パックの保存チェックは `safety-baseline.json` を参照します。

別カテゴリの教材作成が進行中で全体ビルドができない場合は、直前の成功ビルドへ `node scripts/append-food-material.mjs safety` で検証済みの安全教材だけを追加できます。既存の追加処理を共用し、全体ビルドにも専用の検証結果から同じ教材を読み込みます。

今回の反映は上記の追記処理で実施しました。全体再ビルドは別カテゴリの未完成の検証ファイルにより停止しましたが、安全教材44パックの現在の原本・掲載正答・画像は照合済みです。`checks/safety-material-check.mjs` は追加1,574問、既存パック保持、画像参照、正答・誤答判定に合格。`npm run check`、GitHub調査台帳検査、公開版の教材分離検査も合格し、試験管理表は安全カテゴリ **1,955問** に更新しました。全問目視と実ブラウザでの追加検査は未実施です。
