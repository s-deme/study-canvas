# 問題の取り込み形式と教材

「試験・問題を管理」から、画面入力またはUTF-8のJSON・CSVで登録できます。取り込み先の試験を選び、ファイルを指定すると内容・件数・エラーを確認できます。「この内容で登録する」を押すまで保存しません。エラーがあるファイルは全件を拒否し、既存データを保持します。

ファイルは2MB、持込・編集問題は全試験合計2000問まで。既存IDは自動上書きせず、変更は画面の「編集」から行います。問題IDは同じ試験内で一意です。異なる試験では同じIDを使えます。

## JSON

画面からダウンロードできる [見本](../web/sample-questions-v2.json) は、共通本文を参照する選択式と記述式の例です。問題配列、または `passages` と `questions` を持つオブジェクトを取り込めます。

```json
{
  "passages": [{"id": "p1", "text": "共通の資料です。"}],
  "questions": [
    {
      "id": "q1", "type": "single", "passageId": "p1",
      "subject": "", "category": "基礎", "topic": "例題",
      "prompt": "正しい選択肢はどれですか。",
      "options": ["正しい", "誤り"], "answer": 0,
      "explanation": "選択肢1が正解です。", "source": "自作問題"
    }
  ]
}
```

|項目|内容|
|---|---|
|`id`|必須。同一試験で一意、120文字以内。`::`は使用不可。|
|`examId`|省略可。取り込み先と異なる値は拒否。|
|`type`|`single`、`multiple`、`written`、`essay`。|
|`prompt`|必須。問題文。|
|`subject` / `category` / `topic`|任意。科目、学習分野、テーマ。|
|`options`|選択式は異なる文章2〜26個。|
|`answer`|単一選択は0始まりの整数。複数選択は例 `[0,2]`。|
|`modelAnswer`|記述・論述で必須。模範解答。|
|`passage` / `passageId`|共通本文を直接指定、または `passages` のIDを参照。|
|`explanation`|任意。解説。|
|`source` / `sourceUrl` / `year`|出典、HTTPSの原文URL、年度。|
|`explanationSource`|解説の作成者・出典。既定は「登録者による解説」。|
|`images`|任意。`[{"src":"https://example.com/figure.png","alt":"図の説明"}]`。HTTPS画像は通信が必要。|

問題文・共通本文・模範解答・解説はそれぞれ最大50,000文字です。Markdownの表とコードブロック、改行を表示します。HTMLは実行しません。

共通本文は取り込み時に各設問へ展開します。登録後は設問ごとに編集します。画像ファイル自体は取り込みません。

## CSV

[CSV見本](../web/sample-questions.csv)を使えます。1行1設問、見出しはJSONと同じ項目名です。`id` と `prompt` の見出しが必要です。`options`、`answer`、`images` のセルはJSON形式で指定します。共通本文は各行の `passage` に記入します。

カンマ・改行・引用符を含むセルは二重引用符で囲み、セル内の引用符は `""` にします。UTF-8のBOM付きCSVにも対応します。

## 旧G検形式

旧見本 [sample-questions.json](../web/sample-questions.json) と、`category` が0〜9、四択、`answer` が0〜3の旧形式も取り込めます。G検に取り込むと従来どおり `custom:` を補い、`original:` と既存の `custom:` IDは維持します。旧分野番号は順に、人工知能とは／動向／機械学習／ディープラーニング概要／要素技術／応用／社会実装／数理・統計／法律／倫理です。

## 公開するサンプルと利用者の教材

公開する問題データは形式確認用の自作ダミーデータだけです。JSON見本は単一選択と記述式の2問、CSV見本は複数選択の1問、旧形式の見本は四択の1問です。初期状態では登録されず、利用者が取り込んで試せます。

公式試験問題、図表、試験向けの問題集は同梱しません。自作問題や利用条件を確認した教材を登録してください。問題本文・正解・解説・出典は利用者が指定します。登録した教材はブラウザ、または本人専用のクラウドに保存します。


本人用の教材復帰・年度別教材・公開版との分離については [本人用教材の管理](private-material.md) を参照してください。
