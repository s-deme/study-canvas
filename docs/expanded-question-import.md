## 再現と検査

取得は `scripts/fetch-new-exam-candidates.py --repos <取得元...>`、変換は `scripts/prepare-github-candidates.py --repos <取得元...>`。既存の全件ビルドでも再生成できます。今回の新規パックだけを追加する場合は `node scripts/append-food-material.mjs github-candidates` を使用します。既存パックの変更が必要な場合は停止して全件ビルドへ回します。

`checks/expanded-candidates-check.py` は全追加問題の本文・選択肢・正答・疑似コードと原データの対応、および追加前の全パックの内容・メタデータ保持を検査します。`checks/github-candidates-check.mjs` は出典・パック整合、重複除外、採点と不正入力の拒否を検査します。これらは専門家による全件の正答監修を意味しません。

完了結果：3,420問の原データ対応と既存100,915問の保持、全104,335問の形式・図版参照・索引、GitHub62取得元の整合検査に合格。科目Bの生成トレース102問は8パターンすべてを独立計算して正答を確認しました。`npm run check`、管理表再生成、調査台帳検査も合格しました。

専用のヘッドレスChromeで6試験各1問を操作し、科目絞り込み、出典表示、解答前の正解非表示、疑似コード、採点、再読込後の記録保持、390px幅の横はみ出しなしを確認しました。実行記録はローカル `private-data/local-practice/expansion-browser-results.json` に保存。全問題をブラウザで目視確認した意味ではありません。
