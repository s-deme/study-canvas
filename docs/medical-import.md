# 医療・健康の過去問取り込み

2026-10-07実施。現在の登録件数は [試験管理表](exam-inventory.md)、取得元別件数は [取り込み状況](import-status.md) を参照してください。問題本文・PDF・画像は本人用ローカル領域に保存しています。

実施時点の追加は15試験・14,196問（公式8,255問、外部5,941問）。未登録だった7試験にも追加し、カテゴリ合計は23,298問・18試験／教材になりました。合計には既存の自作教材50問を含みます。本人用ビルド、医療取り込みチェック、競合ビルド防止チェック、管理表更新を完了。採点・提供元JSONとの本文／正答一致・選択肢図の解答前表示・画像参照・既存問題の保持を確認しました。

## 取得元と検証範囲

- [厚生労働省の公式公開一覧](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/topics_150873_139_140.html)：診療放射線技師・理学療法士・作業療法士・視能訓練士の2017〜2025年、72冊を取得。65冊から5,091問を追加。公式正答の文字・位置、問題番号の連続、選択肢番号、共通症例のページと原本画像の画素を検査。別冊図が必要な設問や正答が一意でない設問は除外。
- [東洋療法研修試験財団](https://ahaki.or.jp/exam/archives/)：2021〜2026年のあん摩マッサージ指圧師・はり師・きゅう師。公式正答HTMLと問題PDFを照合。表紙の出題範囲を確認し、はり・きゅうの共通問題と各専門問題を振り分け。共通問題はそれぞれの国家試験で演習できる問題として数える。
- [医療機器センター](https://www.jaame.or.jp/ce/past-test.html)：2026年第39回臨床工学技士の午前・午後。[公式正答HTML](https://www.jaame.or.jp/ce/siken17/hpSEITO.html)に照合。複数正答扱いを除外し178問を収録。上記東洋療法分と合わせ、38冊・3,164問。
- [JMed48k/JMed48k](https://huggingface.co/datasets/JMed48k/JMed48k)：医療11職種、各5年度分の公開JSON・設問図・選択肢図。コミット `817f1879f63e1c91f9d01fd2ff60ac44559e3dfb` を固定。55ファイルの12,577レコードから、公式収録済み・不備等を除外して5,941問を変換。提供元READMEの評価対象件数12,484と、今回取得した全レコード数は区別する。全48,862問の公開・取り込みを意味しない。[関連論文](https://arxiv.org/abs/2605.22080)とデータセットを出典として記録。

JMed48kの正答は提供元の値であり、今回独立して公式正答へ照合したものではありません。出典欄・パックの検証欄にもその旨を表示します。文字化け、不完全な選択肢、抽出上の重複選択肢、数値記入、削除・代替正答、選択数との不一致を除外。`answer_img` は選択肢・別冊の図であり、解説画像として隠しません。全選択肢が図のみの場合、図と選択肢番号を提示します。画像は取得時のバイト列のSHA-256とデコード可否を検査しています。

JMed48kは **CC-BY-NC-4.0**。原文LICENSEを保存し、ハッシュを検査。非商用の本人用ローカル教材として扱い、クラウド用ビルドは停止します。財団公開分も利用許諾確認前の公開配布を避け、`localOnly` を付けています。全問の目視確認・理由解説の作成・現在の医療制度への改訂は未実施です。

## 重複と保留

公式原本の試験ID・年度・午前午後／問題ブロック・問題番号を優先し、JMed48kの同じ設問を除外。既存GitHub候補を含む本文・共通本文・選択肢の一致も同一試験内で検査。取り込み開始時の902パックと比較し、899パックのハッシュ一致を確認。別カテゴリの同時取り込みで変わった建築士候補3パックは、元の1,108問が331問継続・777問公式原本へ置換され、年度・科目・問題番号・正答が一致することを確認しました。既存の医療問題は改変・欠落していません。

厚労省の2018年PT・OT（4冊）、2019年視能訓練士（2冊）、2023年診療放射線技師午後（1冊）は、原本から問題番号を確実に抽出できず保留。取得済み冊子・保留問題は登録件数へ加算しません。JMed48kの当該年度から読める問題が入る場合も、公式原本の検証済み登録とは区別します。

GitHubでは [IgakuQA119](https://github.com/naoto-iwase/IgakuQA119) と [nmle-rta](https://github.com/iKora128/nmle-rta) を追加調査。IgakuQA119の固定コミット `09a892bd18bf3803597563e965e2627a2ac866a8` を記録しましたが、今回この候補からの独立した取り込み・正答検証は未実施。[調査台帳](github-exam-search.json)へ追記しています。既存の医師・歯科医師・看護系GitHub由来教材は保持しています。

公認心理師、言語聴覚士、歯科衛生士、歯科技工士、救急救命士、登録販売者には未収録領域が残ります。東京都登録販売者の公式問題・正答も調べ、一部原本を取得しましたが未収録です。今回未収録であることは、公開過去問が存在しないという意味ではありません。

## 再生成・検査

```powershell
python scripts/prepare-medical-official.py
python scripts/prepare-medical-council.py
python scripts/verify-github-material.py --medical
python scripts/prepare-medical-material.py
npm run build:private
node checks/medical-material-check.mjs
npm run inventory:exams
```

公式分は `medical-verified-report.json` と `medical-verification.json`、外部分は `medical-report.json` を保存。公式照合と外部の提供元正答を同じ検証済み状態にまとめません。最後のチェックは、採点、選択肢図の解答前表示、供給JSONとの正答・本文一致、画像参照、重複、既存パックの保持を検査します。
