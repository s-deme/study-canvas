## 学習方法

`Webアプリを起動.cmd` から本人用版を起動し、対象試験を選択します。「科目」で **自作・分野別演習** を選ぶと今回の教材に絞れます。回答を入力して模範解答・解説を表示し、「できた／一部できた／要復習」で自己評価します。既存の記述式と同様、選択式専用の練習模試には入りません。

出典は「自作予想・分野別練習問題（AI生成、公式過去問ではありません。専門家監修なし）」と表示します。公式の正答照合や専門家による監修を実施したとは表示しません。

## 再生成・検証

```powershell
python private-data/local-practice/author.py
python private-data/local-practice/author.py --check
npm run build:private
node checks/local-practice-check.mjs
python private-data/local-practice/check.py
npm run check
npm run inventory:exams
```

- 作成プログラムはPythonのコードを実行し、SQLをインメモリSQLiteで実行して模範解答を作ります。抽出・射影・基本集計はPythonで求めた別の結果とも比較します。
- 計算問題は式の評価値と別途指定した期待値を照合します。サイコロの問題は36通りを全列挙し、指定した該当件数と照合します。
- `--check` は再生成結果と保存済みデータの一致を読み取り専用で検査します。Python/SQLiteのバージョンが変われば再確認が必要です。
- `check.py` は全候補の解答を再実行・再計算し、別途指定した11問の解答を確認します。追加前100,077問は問題ごとのハッシュで変更・削除がないことを検査します。
- ローダーは問題、生成プログラム、解答照合記録のSHA-256、試験ID、問題ID、解答の一致を検査します。生成プログラムをアプリやビルド時に実行することはありません。
- `checks/local-practice-check.mjs` は誤った登録先、パス逸脱、改変、解答照合記録との不一致、重複除外を検査し、本人用ビルドがある場合は実際の `MaterialLibrary` で各試験を読み込みます。

参照した仕様は [Python 3.12公式ライブラリ文書](https://docs.python.org/3.12/library/)、[SQLite SELECT仕様](https://www.sqlite.org/lang_select.html)、[集計関数](https://www.sqlite.org/lang_aggfunc.html)、[ウィンドウ関数](https://www.sqlite.org/windowfunctions.html)です。設問用のコード・架空データ・数値条件・日本語の設問と解説は独自作成しています。
