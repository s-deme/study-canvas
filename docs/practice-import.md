## 再生成・検査

`scripts/fetch-new-exam-candidates.py` で固定コミットの原本・参照図版を取得し、`scripts/prepare-github-candidates.py` で変換します。Excel読取りには同梱Pythonのopenpyxlを使用します。`--repos` で対象を指定すると既存の他取得元の変換結果を保持します。

検査コマンド：

```powershell
npm run build:private
python checks/practice-candidates-check.py
node checks/github-candidates-check.mjs
node checks/private-material-check.mjs
npm run check
npm run inventory:exams
```

追加前の問題ハッシュはローカル `private-data/github-candidates/practice-baseline-questions.json` に保存しています。全既存問題の本文・正答・メタデータ保持、新規の出典との対応、並べ替え順序、穴埋め、採点、図版ハッシュ、試験別パック、公開版への混入防止を検査します。正答・解説の専門的な正しさの全件検証は含みません。

完了結果：既存97,510問のハッシュ保持、新規6取得元2,311件の出典対応、AWS並べ替え24件の順序、全99,845件の形式・画像参照・採点・同期、GitHub56取得元の検査に合格しました。`npm run check`、調査台帳検査、差分の空白検査も合格。仮画像14問は除外した完成ビルドで再検査し、管理表を再生成しました。実ブラウザでの新規全問題の表示確認や、専門家による内容監修は実施していません。
