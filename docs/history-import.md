## 形式と検証範囲

歴史の共通本文・地図を設問間で共有し、下線箇所は「【下線：…】」で保持。問題ページと採点結果を保存し、正解・解説を照合します。採点フォームの認証・CSRF用フィールドは保存しません。

地理は設問番号と正答表のセル座標を照合し、4択・6択を問題の指定に従って区別します。先行する共通資料ページも含め、本文・図表を再構成せず原本の画像で表示します。専門の記述・作図は大問単位で1問と数え、公式解答ページを回答後に表示して自己採点します。枝問や作図の自動採点は行いません。

原本・問題データ・画像のSHA-256、全選択問の正答対応、原本と生成画像の画素一致、問題側に解答ページが混入していないこと、アプリの採点、全11区分の件数、既存教材パックの不変を検査します。代表ページは画像でも確認します。全設問の本文・図・選択肢の目視確認は未実施です。地理の理由解説は未収録です。

すべて`localOnly`として本人用ローカルビルドに反映します。公開版やクラウドへの配備は行っていません。資料は著作権のある公式教材であり、再配布用の許諾を確認したものではありません。

## 非収録

- 歴史検定の本試験過去問：公式公開の解答・解説だけでは設問本文を復元しません。販売中の書籍・PDF問題集は購入していません。
- 検索で見つかった地図地理検定第42回基礎の旧URLは404で取得不能。旧資料の番号を推測してURLを総当たりしていません。
- 共通テスト、高卒認定、通訳案内士等はこの11区分の検定と異なるため、検定名を付け替えて収録しません。既存の通訳案内士教材は保持しています。

## 再生成・検査

```powershell
python scripts/prepare-history-material.py --fetch
python scripts/prepare-history-material.py
npm run build:private
node checks/history-material-check.mjs
npm run inventory:exams
```

取得・採点結果・基準ビルドは`private-data/github-material/history-*.json`とHTML/PDF、変換結果は`prepared/history-report.json`、専用検証記録は`prepared/history-verification.json`に保存します。変換時に全パックを検査し、全件成功した場合のみ検証記録を生成します。カテゴリ別ローダーが検証ハッシュを確認してから読み込みます。`--fetch`は公式無料練習問題の取得と採点を再実行します。教材本文は公開リポジトリへ追加しません。

別カテゴリの取り込みが未完了で全体ビルドが停止する場合、今回使用した既存の追記処理 `node scripts/append-food-material.mjs history` で、最後に成功したローカル版へ検証済みパックだけを追加できます。既存パックのハッシュを検査し、共有ビルドロックを取得してから追記します。通常の全体ビルドにも歴史・地理ローダーを追加しています。
