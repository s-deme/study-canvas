# study-canvas — 資格・試験学習

[ソースコード・Issue](https://github.com/s-deme/study-canvas)

study-canvasは、利用者が自分で試験と問題を登録し、演習・復習・学習記録を管理する個人学習用Webアプリです。スマホ・PCのブラウザで使え、任意の試験・科目・分野を追加できます。広告はありません。

**本プロジェクトの公開対象は問題登録と学習の仕組みです。** すべての試験は問題未登録で始まります。試験問題集・公式問題・図表は同梱せず、JSON・CSVの形式確認用サンプルだけを公開します。画面入力、JSON・CSV取り込みで自分の問題を登録してください。

ローカル版はブラウザに保存し、クラウド版は本人限定ログインと端末間同期を利用します。GitHub Actionsは`main`へのpush・プルリクエストでテストとビルドを実行します。本番への配備は手元から行います。[GitHubでのチェックと手動配備](docs/cloud.md#githubでのチェックと手動配備)

## PCで始める

Python 3が入っているWindowsでは、`Webアプリを起動.cmd` をダブルクリックしてください。ブラウザで **http://localhost:8765/** が開きます。終了は起動ウィンドウでCtrl+Cです。

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

`web/index.html` を直接開かず、HTTPサーバー経由で使ってください。ローカル版はnpmのインストールやビルドは不要です。

## 主な機能

- 試験ごとの出題・復習・検索・成績・直近30回の履歴。
- 画面から試験・問題を登録・編集。科目と分野は任意。
- 単一選択・複数選択の自動採点、記述・論述の模範解答と自己評価。
- 共通本文、表、コード、図の表示。図はタップして拡大。
- 今日の10問、科目・分野別演習、復習、ブックマーク、選択式の練習模試。
- JSON・CSV取り込みと保存前の確認、全試験のバックアップ・復元。
- 途中の演習・記述中の回答の保存、既存G検データの移行。
- スマホ向けレイアウト、ライト・ダークテーマ、キーボード操作。
